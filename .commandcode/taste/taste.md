# User Preferences

## PR Management
- Prefers the GitHub CLI (`gh`) for all pull request operations: `gh pr view`, `gh pr list`, `gh pr edit`. Confidence: 0.9
- Wants PR descriptions compressed/compact — short summary plus a validation/test list rather than long prose. Confidence: 0.8
- Insists bug/finding code identifiers (e.g., `F-123`, finding codes) be stripped from PR text. Confidence: 0.9

## Workflow Ordering
- Finish and validate local changes first, then update the PR text — never edit the PR before local work is complete. Confidence: 0.7
