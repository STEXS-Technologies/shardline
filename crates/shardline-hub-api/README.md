# shardline-hub-api

Hugging Face Hub compatible REST API frontend with repository management,
Git Smart HTTP, and webhook handling. Implements the Hub API specification
for model, dataset, and Space repositories, including Git Smart HTTP protocol
for `git push`/`git pull` workflows, LFS batch API, webhook delivery, and
token-based authentication. Exposed via the Hub frontend flag.

See the [main Shardline README](../../README.md) for the project overview.
